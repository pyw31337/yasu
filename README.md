# 야수의 심장 1980

1980년, 1,000만원으로 시작하는 주식 투자 생존 시뮬레이션.  
레버리지와 사채를 활용해 2025년까지 살아남아라.

실제 코스피 연도별 수익률과 주요 역사적 사건(3저 호황, IMF 외환위기, 닷컴버블, 글로벌 금융위기, 코로나 등)을 기반으로 한 사실적인 게임입니다.  
STONKS-9800 등 유사 게임의 장점(스트레스/리스크 관리, 이벤트 선택, 성취 시스템, 시각적 피드백)을 벤치마킹해 리뉴얼했습니다.

## 플레이 방법

1. `index.html`을 브라우저에서 열기
2. 매년 주식 비중과 레버리지 배율 결정
3. 역사적 뉴스와 선택 이벤트를 확인하고 대응
4. 2025년까지 생존하거나 파산

## 주요 개선점 (리뉴얼)

- 실제 코스피 연도별 수익률 반영 (1980–2025)
- 주요 역사적 사건 이벤트 + 주요 위기 연도 선택지 (IMF, 닷컴, 2008, 코로나)
- 레버리지 / 사채 이자 시스템 (위기 시 고금리)
- 리스크 미터, 순자산 차트 (Canvas)
- 성취 시스템, 로컬 저장/이어하기
- 효과음 (Web Audio API 절차적 생성), 플래시·슬라이드 애니메이션
- 야수의 심장 시각 요소, 다크 시네마틱 UI
- 단일 HTML 파일로 즉시 플레이 가능

## 데이터 근거

- 코스피 연도별 수익률: Wikipedia KOSPI Annual Returns, SimianX KOSPI Returns by Year
- 주요 사건: IMF 외환위기, 3저 호황, 닷컴버블 붕괴, 2008 금융위기 등 공식 기록
