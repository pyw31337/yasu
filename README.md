# 야수의 심장 1980

1980년, 1,000만원으로 시작하는 주식 투자 시뮬레이션.
레버리지와 사채를 활용해 2025년까지 살아남으세요.

실제 한국 증시 역사적 사건과 코스피 흐름을 기반으로 한 사실적인 시뮬레이션 게임입니다.

## 플레이 방법

1. `index.html`을 브라우저에서 열기
2. 매년 포트폴리오 비중과 레버리지 결정
3. 역사적 뉴스 이벤트를 확인하고 대응
4. 2025년까지 생존하거나 파산

## 특징

- 실제 코스피 연도별 대략적 수익률 반영
- 주요 역사적 사건 (건설주 후유증, 3저 호황, IMF, 닷컴버블, 금융위기 등) 이벤트
- 레버리지 / 사채 시스템
- 시대적 분위기를 느낄 수 있는 뉴스 카드

Made with historical accuracy in mind.
